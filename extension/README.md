# GLaDOS Check-in 浏览器插件（0.2.0 安全修订预览）

保留 PR #44 的中英文本地化与 Chrome / Edge 后台设置提示，感谢 Unexpectedlyc。
这是基于 main 的隔离修订，尚未发布。Mock 测试不是实际浏览器或真实账号验收。

## 怎么使用

1. Chrome / Edge 140+ 打开扩展管理页，启用开发者模式，加载本目录（不是仓库根目录）。
2. 在官方网站自行登录，然后在弹窗点击“连接当前账号”。只读查询会绑定当前邮箱的 SHA-256 标识，显示脱敏提示；不要求粘贴 Cookie。
3. 默认暂停。可明确选择尝试一次，或确认开启北京时间 09:30 / 12:30 / 20:30 定时尝试。
4. 需要交互验证时，由用户在官网处理。插件不会解答、模拟或隐藏 CAPTCHA，也不自动兑换。
5. 遇到“结果未知”或“需要处理”先查看保留的官网页面与流水。确认后可清理任务记录，再另行选择尝试。清理不会自动重试。

浏览器进程必须运行，休眠/关机可能错过时段；不承诺精确准点，也不在启动时补发签到。后台设置提示只提供设置地址，不修改浏览器设置。

## 状态与安全边界

| 状态 | 含义 |
| --- | --- |
| PREPARING / PAGE_OPEN | 持久任务已创建，等待绑定页面或提交许可 |
| SUBMITTING | 已持久化一次性提交许可；不表示官网已成功处理 |
| OBSERVED | 最近返回的前 10 条流水中发现北京时间今日的明确 checkin 正记录；不归因于插件这次操作 |
| UNKNOWN | 可能已提交但结果不确定；暂停，不自动重发 |
| NEEDS_USER | 页面、身份、验证或恢复过程需要人工检查；暂停 |

单 worker 串行任务避免并发重复打开页面；发出点击许可前持久化 SUBMITTING。后台重启遇到未完成任务转为 UNKNOWN / NEEDS_USER，不重复提交。不能宣称分布式“严格幂等”或“多跑一定更成功”：官网、其他设备和人工操作不受此锁控制。

提交前会再次读取账号，并在流水读取前后比对身份。但浏览器登录态是可变共享状态，最后校验与页面点击之间仍有时间窗口，不能彻底锁定账号。任务期间不要切换账号。首次使用请仅在测试账号独立浏览器配置中验收。

暂停/清除使尚在等待的提交许可失效，并串行清理记录与闹钟；已经交给页面的点击不能撤销。扩展不自动关闭任何页面。清除本地记录不会退出官网账号。

只信任固定官网、拥有的 tab、顶层 frame、document、task 对应的扩展消息；不把页面传来的任意成功字段当结果。不用 isolated world 的 fetch/XHR 猴子补丁冒充网络监听。积分为读取时快照，非实时保证。补偿、退款、兑换或未知业务正流水不当签到。

## 存储与权限

- 仅 storage / alarms，以及固定 glados.cloud 主机权限。无 cookies API、无通知权限、无第三方服务。
- 任务账本保存在限制为 TRUSTED_CONTEXTS 的 storage.local；可跨重启。仅存哈希账号标识、脱敏标签、任务和积分摘要，不存密码、Cookie、完整响应。
- 邮箱哈希不是匿名化，也不是密码存储；脱敏标签仍可能透露邮箱域名。设备用户可清除扩展记录。
- 不用 storage.session 承担跨重启账本。旧版隐式启用状态不迁移，更新后默认暂停。

## 开发验证

运行 `cd extension && npm test`。当前测试不联网，覆盖默认关闭、显式同意、并发、持久提交许可、重启未知态、消息来源、账号切换、非签到流水、取消竞态和北京时间跨日。

尚需真实 Chrome / Edge 验证：实际加载、官网 JSON 契约、会话复用、按钮匹配、交互验证交接、授权/暂停/清除、worker 中断和浏览器重启。官网返回格式不匹配时应停止，不猜测身份或成功。当前不保证会话可复用、不保证官方接受签到、不保证免费账号积分数量。

## 扩展内只读控制台

在扩展管理页打开“扩展选项”，可查看保存的脱敏账号、自动化设置、最近任务与积分快照。控制台的独立只读消息只访问本地记录，不调用执行引擎或官网接口；它不提供实时余额。没有数据时显示空状态，不塞入演示数字。控制台不接受执行指令，操作仍在弹窗显式完成。

控制台的任务与启用标识仅代表已保存状态，不证明调度仍在运行。SUBMITTING 在提交许可发出前就会持久化，所以只表示进入提交阶段，可能尚未点击；不据此宣称许可已发送、已点击或签到成功。
